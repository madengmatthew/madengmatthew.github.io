# Jiale Li — personal website

Personal academic homepage: <https://madengmatthew.github.io/>

A compact, single-column page with background, research interests, experience, projects, education, and a GitHub link. Built with HTML and CSS, with no dependencies or JavaScript.

## Edit

- `index.html`: page content and links.
- `styles.css`: desktop, mobile, and print layouts.
- `favicon.svg`: browser tab icon.
- `404.html`, `robots.txt`, `sitemap.xml`: hosting support.
- `.nojekyll`: serves the static files directly.

Edit the files and commit to `main` to update GitHub Pages. The publishing source is the root of `madengmatthew/madengmatthew.github.io`.

To preview locally, run `python3 -m http.server 8000` in this folder and open <http://localhost:8000>.
