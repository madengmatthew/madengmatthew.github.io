Console Text Editor

Code · Documentation

A command-driven text editor written in Python. It works with a multiline document in the terminal: enter a short command to move the cursor, edit text, or rearrange words and lines. The implementation uses only the Python standard library.

Editing features
  • Navigation: move by character or word, jump to either end of a line, or enter a line number to move directly to it.
  • Text editing: insert or append text at the cursor or line boundaries; delete individual characters, words, or whitespace spans.
  • Word operations: use sw or sb to swap the current word with its next or previous neighbor.
  • Multiline editing: add lines with o and O, delete a line with dd, and move whole lines with J and K.
A short editing session
Implementation

The document is stored as a list of strings, with separate row and column positions for the cursor. Input is classified as a command, a command with text, or a line number; dispatch dictionaries then call the corresponding editing function.

Regular expressions identify words as runs of non-whitespace characters, providing the boundaries for navigation, deletion, and swapping. ANSI escape sequences highlight the current character, and an optional * marker identifies the active line.

Try it locally

Download editor.py and run python3 editor.py in a terminal. Enter one command at each > prompt and press Enter. Put text directly after insertion commands, as in iHello world. Use ? for help and q to quit.

Text is stored in memory only. File loading and saving, and undo/redo, are not implemented.
